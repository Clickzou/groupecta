Diaporama plein écran de la page d'accueil
==========================================

Déposez ici vos 4 images, idéalement nommées :
  slide-1.jpg
  slide-2.jpg
  slide-3.jpg
  slide-4.jpg

Recommandations :
- format paysage, ~1920x1080 px (ou plus), optimisées (< 400 Ko chacune)
- sujets : voyage d'affaires, congrès/événement, séminaire, voyage

Puis renseignez le champ `src` de chaque slide dans :
  src/lib/site.ts  ->  heroSlides
exemple :  { src: "/hero/slide-1.jpg", alt: "Voyage d'affaires", ... }

Tant que `src` reste vide, un dégradé aux couleurs CTA s'affiche à la place.
